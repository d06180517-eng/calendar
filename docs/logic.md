# Логика и правила

Вся логика живёт в `lib/data/app_state.dart` (класс `AppState`), модели — в
`lib/data/models.dart`. Ниже — правила, на которые опираются экраны и тесты.

## Модели

| Модель | Поля | День в календаре |
|---|---|---|
| `Story` | `media`, `overlays`, `keepInCalendar`, `groupId`/`partIndex`/`partCount` (части видео), `viewers`, `text` (для текстовой сторис) | дата `createdAt` |
| `Plan` | `text`, `planAt`, `remind` | дата `planAt` |
| `DiaryPost` | `date`, `text`, `photos`, `weather`; `tags` берутся из текста | `date` |
| `Comment` | `text`, `replyToId` (id корневого комментария), `likes` | — |
| `Chat` / `ChatMessage` | участники; текст, фото, `sharedPostId`, `replyToStoryId`, `read` | — |
| `AppNotification` | `kind`, `fromUserId`, `postId`, `text`, `read` | — |
| `AppUser` | имя, ник, о себе, город, ссылка, день рождения, цвет/фото аватара, `isPrivate` | — |

Все записи (`Story`, `Plan`, `DiaryPost`) наследуют `Post`: `id`, `authorId`,
`createdAt`, `visibility`, `likes`, `comments`.

## Аудитория (кто видит)

`Audience`: **Только я** / **Подписчики** / **Все**. Проверка — `canSee(post, viewer)`:

1. Автор видит всё своё.
2. Если между людьми есть блокировка — не видно.
3. «Только я» — никому, кроме автора.
4. «Подписчики» — тем, кто подписан на автора.
5. «Все» — всем, но у **закрытого профиля** «Все» = только подписчики.

Значения по умолчанию:

| Что | По умолчанию |
|---|---|
| Сторис | Все |
| Свободная пометка (текстовая сторис) | Все |
| Пост дневника | Все (чтобы попадать в ленту) |
| План | Только я |

## Подписки и закрытый профиль

- Подписка на открытый профиль — сразу; на закрытый — запрос.
  Владелец принимает или отклоняет его в уведомлениях.
- Если профиль сделать открытым, все ожидающие запросы принимаются.
- Блокировка: обоюдно скрывает записи, снимает подписки в обе стороны,
  запрещает переписку, скрывает комментарии заблокированного.
- Жалоба на запись автоматически скрывает её у пожаловавшегося.

## Сторис

- В ленте сторис живёт **24 часа** (`isActiveAt`).
- В календаре: первые 24 часа — всегда; потом — только если
  `keepInCalendar = true`. Автор может поменять это в любой момент,
  для частей одного видео — сразу для всех.
- **Видео длиннее 60 секунд** режется на части по 60 с, без перекодирования:
  каждая часть хранит отрезок `start`–`end` исходного файла, плеер
  проигрывает только его. Части имеют общий `groupId`, идут подряд,
  отметки людей — только на первой части. 150 с → 0–60, 60–120, 120–150.
- Отметка @человека в сторис создаёт ему уведомление.
- Просмотры записываются, когда сторис открыта (кроме своих).

## Пометки

- **Свободная** = `Story` с `text` и однотонным фоном
  (`media.placeholder = [цвет, цвет]`). Живёт по правилам сторис.
- **План** — запись на будущее: появляется в календаре в день `planAt` со
  значком 🔔, в ленту не попадает никогда. При «Напомнить» ставится
  локальное уведомление на `planAt` (только если время в будущем).
- Текст обеих — не длиннее 300 символов (`maxNoteLength`), лишнее обрезается.

## Дневник

- У каждого дня свой дневник-канал; постов за день — сколько угодно.
- Пост без текста и без фото не публикуется.
- Пост можно написать в прошлый день: он попадёт в тот день, время — текущее
  время суток.
- **Погода** запрашивается при открытии сегодняшнего дневника и
  прикрепляется к первому посту за сегодня (если у дня её ещё нет).
  Источник — Open-Meteo по приблизительной геопозиции; на всё — не больше 20 с.
- **#теги** — слова с `#` в тексте (буквы, цифры, `_`), приводятся к нижнему
  регистру. Поиск по тегу — только по своим постам, новые сверху.
- В экране дневника переход по дням идёт по списку «дни с видимыми постами +
  открытый день (+ сегодня для своего)». Список фиксируется при открытии,
  чтобы страницы не прыгали.
- Напоминание о дневнике — ежедневное локальное уведомление
  (по умолчанию 21:00, настраивается).

## Лента

`feed()` собирает записи:

- не свои, не скрытые, видимые мне;
- сторис — только активные (младше 24 ч);
- планы — никогда;
- посты дневника — за последние 7 дней (и не из будущего).

Порядок: сначала **близкие** (на кого я подписан и кто подписан на меня),
потом остальные; внутри группы — новые сверху. Части одного видео всегда идут
подряд и по порядку.

## Лайки и комментарии

- Лайк — переключатель; двойной тап только ставит лайк (не снимает).
- Ответ на ответ всё равно попадает в ветку корневого комментария.
- Удаление корневого комментария удаляет и всю ветку.
- Уведомления: лайк записи, комментарий автору записи, ответ автору
  комментария (если это не автор записи), лайк комментария.
  Себе уведомления не приходят.

## Профиль: счётчики

- **Опубликованные дни** — дни (не в будущем), где есть запись не «Только я»,
  которая видна в календаре.
- **Серия 🔥** — сколько дней подряд есть записи (кроме планов), считая от
  сегодня; если сегодня ещё ничего нет — от вчера.

## Чаты

- Писать можно всем, кроме заблокированных (и себе нельзя).
- Пустое сообщение не отправляется.
- Ответ на сторис отправляет сообщение со ссылкой на сторис.
- «Поделиться» отправляет запись в выбранный чат.
- Непрочитанные считаются по сообщениям собеседника; открытие чата помечает
  их прочитанными.

## Вход (демо)

- Email должен содержать `@` и быть не короче 5 символов; пароль — от 6.
- Регистрация: ник без `@`, не пустой и не занятый.
- Все способы входа ведут в демо-аккаунт `me`.
