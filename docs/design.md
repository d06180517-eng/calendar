# Дизайн-система

Настроение: светлое, воздушное, «бледно-бирюзовый и белый». Минимализм в
навигации (чёрно-белые контурные иконки), цвет — в контенте.
Код: `lib/ui/theme.dart`, `lib/data/models.dart` (цвета текстовых сторис),
`lib/ui/widgets/story_overlays.dart` (шрифты и цвета надписей сторис).

## Палитра: базовые токены

| Токен (`AppColors`) | HEX | Где используется |
|---|---|---|
| `turquoise` | `#3FA9A0` | Primary: кнопки, акценты, рамка «сегодня», #теги, значки |
| `turquoiseLight` | `#D9F3F0` | `primaryContainer` (светлая тема), фон дней с записями, карточка дневника в ленте |
| `turquoiseDarkBg` | `#1C3533` | `primaryContainer` (тёмная тема) |
| `text` | `#1F2D2C` | Основной текст в светлой теме, текст на светлых фонах |

## Палитра: роли темы (`ColorScheme`)

Схема строится из `ColorScheme.fromSeed(seedColor: #3FA9A0)` и
переопределяет:

| Роль | Светлая | Тёмная |
|---|---|---|
| `primary` | `#3FA9A0` | `#3FA9A0` |
| `surface` (фон экранов, AppBar, листы) | `#FFFFFF` | `#121515` |
| `onSurface` (текст) | `#1F2D2C` | `#E8F0EF` |
| `primaryContainer` | `#D9F3F0` | `#1C3533` |
| `onPrimaryContainer` | `#1F5E58` | `#BFEDE7` |
| `surfaceContainerHighest` (карточки, поля ввода, посты дневника) | `#F3FAF9` | `#1E2423` |
| `outlineVariant`, `onSurfaceVariant` | из seed | из seed |

Тема переключается в настройках: как в системе / светлая / тёмная.
Лента и просмотр сторис всегда тёмные (чёрный фон, белые иконки).

## Иконки

Material Icons, контурные; активная вкладка — залитая версия.
Цвет навигации — чёрный (в светлой теме) или белый (в тёмной и в ленте).

| Смысл | Иконка |
|---|---|
| Аудитория: только я / подписчики / все | `lock_outline` / `group_outlined` / `public` |
| План, напоминание | `event_outlined`, `notifications_active_outlined`, 🔔 в календаре |
| Дневник | `menu_book_outlined` |
| Свободная пометка | `text_fields` |
| Лайк | `favorite_border` → `favorite` (красный) |
| Комментарии / поделиться / ещё | `mode_comment_outlined` / `send_outlined` / `more_horiz` |

## Принципы

- Скругления везде; круглых аватаров нет — квадрат со скруглением, как ячейки
  календаря.
- Настроение и эмоции — не смайликами, а цветом (цвет фона текстовой сторис).
- Интерфейс проверяется на узком экране 360 dp: длинные строки ellipsize,
  ряды с кнопками переносятся (`Wrap`) или сжимаются (`Expanded`).
